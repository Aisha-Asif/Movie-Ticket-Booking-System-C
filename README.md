# 🎬 Movie Ticket Booking System  

*A command-line movie ticket reservation system that provides a smooth and efficient booking experience for users, members, and administrators. Developed in C as a first-semester project for BSCS at FAST (Fall 2023), the system simulates real-world functionalities of a cinema's ticketing and membership services using file handling, structures, and modular programming.*  
[![License](https://img.shields.io/badge/License-Academic-blue.svg)](https://github.com/your-username/movie-ticket-booking)  

---

## 📌 Project Overview  
Replaces traditional cinema booking inefficiencies with:  
✔ **User-friendly ticket booking**  
✔ **Membership discounts**  
✔ **Admin-controlled movie management**  
✔ **Persistent data storage** (via `.txt` files)  


## 🛠 Technologies Used  
| Category       | Components                                                                 |  
|----------------|---------------------------------------------------------------------------|  
| **Language**   | C                                                                         |  
| **Data Structures** | Structures, Pointers, 1D/2D Arrays                                  |  
| **File I/O**   | `.txt` files for movie listings, bookings, memberships                    |  
| **Key Concepts**| User-defined functions, recursion, `strcmp/strcpy`, dynamic menus        |  

---

## 🚀 Features  
### 👨‍💼 **Admin Mode**  
- Add/update/delete movies  
- View/cancel bookings  
- Set member discounts  
- Reset daily data  

### 🎟️ **User Mode**  
- Browse movies  
- Book/cancel tickets  
- Apply for membership  

### 👑 **Member Mode**  
- Exclusive discounts  
- View booking history
